# Code of conduct

Polix follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, criticise ideas and code rather than people, and keep discussions on
topic. Harassment, insults and personal attacks are not tolerated in issues, pull requests, discussions or any other
space of the project.

The maintainer may edit or remove comments, close threads and block participants who break this code.
Report a problem to the maintainer, [@mlophez](https://github.com/mlophez); reports are kept confidential.
